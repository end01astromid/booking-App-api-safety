SLOTBOOK
Сервис онлайн-бронирования на NestJS.
Основная идея — нормально обработать бронирование по времени, чтобы один и тот же слот нельзя было занять дважды.
Можно бронировать коворкинги, переговорки и записываться к врачам.

   Что умеет?
  1 - Регистрация и вход (Jwt)
  2 Создание ресурсов (коворкинг / переговорка / врач)
  3 Создание брони
  4 Проверка пересечения времени (если слот занят — возвращает ошибку)
  5  Просмотр своих броней
  6 - Отмена брони (через смену статуса)


  2.Использование технологий
  NestJS MongoDB + Mongoose -
  JWT + Passport bcrypt/class-validator/TypeScript

      3.Как запустить?
  1.Клонируй репозиторий git clone <ссылка-на репозиторий>
  2. Установи зависимости npm install (есть в package.json)
  
  4. Создай файл .env    [PORT=3000
                         MONGODB_URI=mongodb://localhost:27017/slotbook
                         JWT_SECRET=SECRET_KEY ]

         5. Запуск
         npm run start:dev
         Сервер будет на http://localhost:3000



     6.Как устроена проверка времени
    Перед созданием брони система ищет пересечения
    берёт все активные брони этого ресурса
    проверяет, пересекается ли новый интервал с уже существующими
    если пересечение есть — бронь не создаётся
    Это основная бизнес-логика проекта.!
