# SlotBook — API для онлайн-бронирования

Сервис онлайн-бронирования на NestJS.
Основная идея — нормально обработать бронирование по времени, чтобы один и тот же слот нельзя было занять дважды.
Можно бронировать коворкинги, переговорки и записываться к врачам.

## 🚀 Функционал

- **🔐 Аутентификация:** Регистрация и вход (JWT, Passport, bcrypt).

- **📅 Управление ресурсами:** Создание переговорных, коворкингов, карточек врачей.

- **⏳ Бронирование:** Создание, просмотр и отмена брони (смена статуса).

- **🛡 Бизнес-логика:** Автоматическая валидация наложений времени (система блокирует пересекающиеся интервалы).

## 🛠 Стек технологий

- **Backend:** NestJS (TypeScript)

- **Database:** MongoDB / Mongoose

- **Validation:** class-validator

## 📦 Быстрый запуск

### 1. Клонирование и установка

```bash

git clone <ссылка-на-репозиторий>

cd slotbook

npm install

```

### 2. Настройка окружения

Создайте файл `.env` в корне проекта:

```env

PORT=3000

MONGODB_URI=mongodb://localhost:27017/slotbook

JWT_SECRET=your_super_secret_key

```

### 3. Запуск

```bash

# Режим разработки

npm run start:dev

# Продакшн сборка

npm run build

npm run start:prod

```

Сервер будет запущен на `http://localhost:3000`
